# ♡ Steal a Egg Hub ♡

Script completo e limpo para **Steal a Egg** (Roblox) com interface moderna.

## Features

- **Velocidade** ajustável (aplica de verdade no Humanoid)
- **Fly** estável (WASD + Space / Shift)
- **ESP Visual**
  - Highlight vermelho nos jogadores
  - Nome acima da cabeça
  - Distância em metros em tempo real
- GUI arrastável com efeito RGB
- Tecla **RightControl** para abrir/fechar

## Como usar

1. Abra seu executor (Synapse, Fluxus, Solara, Wave, etc.)
2. Copie o conteúdo de [`StealEggHub.lua`](./StealEggHub.lua)
3. Cole e execute
4. A GUI aparece no meio da tela

> Se for usar como **LocalScript** no seu próprio jogo, troque `game:GetService("CoreGui")` por `player:WaitForChild("PlayerGui")`.

## Controles

| Ação              | Tecla / Como usar          |
|-------------------|----------------------------|
| Abrir / Fechar GUI| `RightControl`             |
| Velocidade        | Toggle + digitar valor     |
| Fly               | Toggle + WASD / Space / Shift |
| ESP               | Toggle ON/OFF              |
