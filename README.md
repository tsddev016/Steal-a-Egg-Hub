# ♡ Steal a Egg Hub ♡

Script completo e limpo para **Steal a Egg** (Roblox) com interface moderna.

## Features

- **Velocidade** ajustável
- **Fly** (mais estável / menos óbvio pro anti-cheat básico)
- **ESP Visual** (Highlight + Nome + Distância)
- **Anti-Taco**
  - Remove ragdoll / molenga
  - Intangível (não toma taco)
  - Reduz knockback
- **Fling** (encosta no player = ele voa longe)
- GUI arrastável com efeito RGB
- Tecla **RightControl** para abrir/fechar

## Como usar

1. Abra seu executor
2. Copie o conteúdo de [`StealEggHub.lua`](./StealEggHub.lua)
3. Cole e execute
4. A GUI aparece no meio da tela

> Se for LocalScript no seu próprio jogo, troque `game:GetService("CoreGui")` por `player:WaitForChild("PlayerGui")`.

## Controles

| Ação              | Como usar                          |
|-------------------|------------------------------------|
| Abrir / Fechar GUI| `RightControl`                     |
| Velocidade        | Toggle + digitar valor             |
| Fly               | Toggle + WASD / Space / Shift       |
| ESP               | Toggle ON/OFF                      |
| Anti-Taco         | Toggle ON/OFF                      |
| Fling             | Toggle ON/OFF (encosta no player)  |

Script fornecido para estudo. Use por sua conta e risco.
